
# Expense Tracker

## Project Description

Expense Tracker is a Python-based application that helps users record,
view, search, and manage their daily expenses. It also calculates total
spending and shows expenses by category.

## Features

- Add new expenses
- View all saved expenses
- Search by category or description
- Delete an expense
- Calculate total spending
- Display category-wise spending
- Save expense records in a JSON file
- Handle invalid input

## Installation and Setup

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Make sure Python is available in your terminal.

No external Python packages are required.

## How to Run

Open the terminal inside the project folder and run:

```bash
python main.py
```

On Windows, you can also run:

```bash
py main.py
```

Follow the menu to add, view, search, or delete expenses.
